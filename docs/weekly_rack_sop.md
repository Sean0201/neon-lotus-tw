# 本週精選(首頁衣架)更新 SOP

首頁最上方的衣架 = 後台「精選商品」裡 **Active** 的商品,依 **Sort Order** 由左到右排列。
每週換一次精選,大約 20–30 分鐘。

---

## 1. 選商品(建議 6–10 件)

| 優先 | 說明 |
|---|---|
| ✅ 上衣、外套、帽 T、毛衣 | 掛在衣架上最好看 |
| ✅ 有庫存、有尺寸 | 已售完的商品衣架上會顯示「已售完」 |
| ✅ 官方有**白底平拍照** | 去背最乾淨(Hades、Dirtycoins 大多有) |
| ⚠️ 只有模特兒照 | 可以去背,但效果較差(例:Bunny Hill) |
| ✅ 鞋子、包包、帽子、桌燈等配件 | 自動放在衣架下方的**木櫃**上(依商品分類;分類是「其他」時依品名判斷) |
| ⚠️ 褲子、裙子 | 掛在衣架上不自然,建議搭配上衣做成套組 |
| ✅ 有多個配色 | 單品檢視會出現色點,可以切換 |

> 衣架件數少於 6 件時,每件之間會自動拉開間距。

## 2. 準備去背圖

每件精選 + 同款每個配色,各一張**透明背景**的 PNG / WebP。尺寸不用管,後台上傳時會自動裁邊並轉成寬 560px WebP。

**方法 A:交給 Claude**
在 Claude Code 說:「本週精選:Hades 挑 2 件、Dirtycoins 挑 2 件……」或直接給商品 ID / 連結。
Claude 會:挑商品(或照你指定)→ 用 `scripts/rack-cutout.py` 去背(含所有配色)→ 產生 SQL → 本機預覽給你看。

**方法 B:自己去背**
用 remove.bg 之類的工具,下載透明 PNG 即可。

**自己跑去背腳本**(需要 Python 3.9–3.13,安裝方式見腳本開頭):

```bash
~/.venvs/rembg/bin/python scripts/rack-cutout.py 照片1.jpg 照片2.jpg
```

輸出在 `output/rack/`。

## 3. 後台設定

後台 → **精選商品(Featured)**

1. **停用上週的精選**:每一列的 Active 開關關掉(不要刪除,之後可以再打開)
2. **+ Add Featured** → 選品牌 → 選商品
3. **衣架去背圖**:上傳這件的去背圖
4. **同款其他配色**:會自動列出同款的每個顏色,各自上傳(上傳後立即儲存,不用按 Save)
5. **Sort Order**:10、20、30…… 數字小的排左邊
6. **Save Featured**
7. 全部設定好後按 **🚀 重建快照 + 發佈**(精選清單讀的是快照,不按不會更新)

列表的「衣架去背」欄可以一眼看出哪幾件還沒上傳。沒有去背圖的商品,衣架上會改用原本商品照當吊牌卡片(不會壞版,但不好看)。

也可以用 SQL 一次設定(Claude 產生的 `db/featured_this_week.sql`):Supabase → SQL Editor → 貼上 → RUN。

### 商品本身的資料(價格、顏色、尺寸、細節照、描述)

都在後台 **商品(Products)** → 編輯該商品:

| 要改的 | 後台欄位 | 衣架上出現在哪 |
|---|---|---|
| 價格 | VND 原價 / 預估價(台幣自動換算) | 衣架下方、單品檢視的國際配送 / 親自帶回 |
| 尺寸、缺貨 | 尺寸列表 + Available 勾選 | 單品檢視的尺寸按鈕(沒勾的會劃掉) |
| 細節照、背面照 | Gallery(📁 上傳) | 單品檢視衣服下方的縮圖 |
| 商品描述 | 中文描述 | 單品檢視的說明文字 |
| 售完 / 特價 | Sold out / 品牌特價 | 「已售完」按鈕 / 特價標籤 |
| 顏色 | 每個顏色是一個獨立商品,品名用「品名 - 顏色」 | 同品名的會自動變成色點 |

> ⚠️ 精選清單、價格、尺寸、細節照,前台讀的都是**快照**:改完要到後台按 **🚀 重建快照 + 發佈**,約 1–2 分鐘後生效。
> 只有衣架去背圖是即時讀取,上傳後重新整理就看得到。

## 4. 確認

打開首頁(手機也看一次):

- [ ] 衣架上的件數、順序正確
- [ ] 每件都是去背衣服,沒有白底照片卡
- [ ] 滑過 / 點一下會翻正,衣架藏在衣服裡、只露出掛勾
- [ ] 點開單品檢視:價格、尺寸、色點、商品照都正常
- [ ] 隨便加一件到購物車,再從購物車刪掉

首頁資料有快取,重建快照後沒看到變化時,用無痕視窗開或等幾分鐘。
同款不同色就算加了好幾件精選,衣架上也只會掛第一件,其他顏色在單品檢視用色點切換。

## 5. 常見問題

| 狀況 | 原因 / 處理 |
|---|---|
| 衣架上是白底照片卡 | 這件沒有上傳去背圖 → 後台補上傳 |
| 切換色點後變成照片卡 | 那個配色沒有去背圖 → 在「同款其他配色」上傳 |
| 衣架露出來 / 衣服歪掉 | 去背圖不夠乾淨(多抓到手、頭髮)→ 換一張平拍照重做 |
| 色點沒有出現 | 同款不同色的品名格式不一致(要是「品名 - 顏色」或「品名 (顏色)」) |
| 精選完全沒顯示 | 後台沒有任何 Active 的精選 → 首頁會自動挑 8 個品牌各一件 |
